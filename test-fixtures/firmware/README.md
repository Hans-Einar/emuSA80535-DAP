# Synthetic SAB80535 firmware fixture

`synthetic-loop.bin` is an exactly 65,536-byte raw CODE image generated by
`scripts/generate-synthetic-fixture.mjs`. The only non-fill bytes are generic
SAB80535 instructions:

- `0x0000`: `MOV A,#01h`
- `0x0002`: `INC A`
- `0x0003`: `SJMP 0002h`

The remainder is the neutral `NOP` byte `0x00`. The loop has no firmware- or
hardware-specific meaning and opens no host endpoint. Regenerate the binary
with `npm run fixture:generate`; `npm run fixture:check` verifies its exact
size and SHA-256 against `synthetic-loop.json`.
